# Teatro Quinta Esencia

Official website for **Teatro Quinta Esencia**, a contemporary theatre collective based in Bogotá.

The site presents the collective's productions, artistic team, collaborators and contact information through a custom-built web experience.

## Website

**https://5esencia.art**

## Project scope

The repository contains the frontend implementation of the public website, including:

- Production and project presentation.
- Responsive navigation and page sections.
- Image and multimedia assets.
- Team and collaborator information.
- Contact and communication interfaces.
- Custom visual design and interaction.
- Progressive Web App assets and service-worker functionality.

## Technology

- HTML5
- CSS3
- JavaScript
- Responsive web design
- Progressive Web App features
- GitHub Pages / custom domain

## Context

The website is part of the digital practice of **Teatro Quinta Esencia**, combining theatre production, visual design and web development.

The project is maintained by Leonardo Merchán and collaborators.
